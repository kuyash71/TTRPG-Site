# Türkçe → English glossary (Schwarzesonne & Umbra Caelis)

Use these renderings everywhere (UI and rules text) so the English site is consistent.

## Never translate (proper names / game names)
- Ability, perk, branch (dal), class, tree, augment, campaign, faith-option names that are already proper nouns (Latin/German/Spanish/English): keep exactly.
- Umbra Caelis stats: **Yalman, Kaçınç, Görü, Giz, Marifet, Hikmet, Efsun, Sebahat, Hakimiyet, Cazibe** (keep, with Turkish letters).
- Schwarzesonne stats: Korp, Agil, Leis, Klang, Krach, Sanita, … (keep).
- World / lore names: Granterra, Es'terra, Kharadon, Starless Night, Kızıl Kıyamet → keep as is, Leit'ateirr, Xitochi, Realm of Sand, Velites, Düskarl, Falltrupp, Savarum, Blaze, Trifarium, Tenebri, Excidis, Aequtris, Vjolfunism, Tvolktur, God of Dreams, Burkut Hanlığı → "Burkut Khanate", Aokiba, etc.
- Currency & items: Lumre, Reichsmark, Düşotu, Blu Mana, Decayed Mana, Primordial Mana, Gletschmetall, Pervitin.
- Vertex, Death Save (Throw), Nat20 / Nat1, GM, RP, Erwachen, Apotheosis, Jinzen, Animus, Gesucht.

## Style
- Second person ("you"), concise, game-manual tone. Keep numbers, signs (+2, −3), dice notation and markdown/HTML tags exactly.
- Keep HTML attributes (`href`, `id`, `class`) unchanged; translate only text nodes.
- Turkish "Örn:" → "e.g.:".
